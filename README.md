## 구성

- **1부 개념 카드 10장** — 정의는 W3C·ICA 표준 그대로, 예시는 전부 『대한민국 국회를 말하다 08 정세균』
- **2부 그라운딩 워크벤치** — 원문 투입 → 개체 추출 → 클래스 배정 → 전거 매핑 → 트리플 잇기 → 검증 → 산출

## 특징

- **의존성 0, API 키 0.** 순수 정적 파일. 25명 이상이 동시에 써도 서버 부하 없음
- AI 추출은 **사전 계산본**. Claude가 실제로 뽑은 결과이며 **틀린 항목이 의도적으로 섞여** 있음
- 도메인·레인지가 선택지를 실시간으로 좁힘 (⑤단계) — 온톨로지가 환각을 줄이는 원리를 손으로 체험
- 검증 6종 규칙 + 책 뒤 찾아보기와 재현율 대조

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 구조·스타일 |
| `app.js` | 개념 카드 10장 + 워크벤치 로직 |
| `data.js` | 자동 생성 데이터 (수정 금지) |
| `build_data.py` | 데이터 빌더 |
| `_speakers_raw.json` | 역대 국회의장단 전거 마스터 (총서 부록 파싱) |
| `_index_gold.json` | 찾아보기 정답지 (총서 색인 파싱) |
| `_paras_clean.json` | 실습 원문 8단락 |

## 데이터 재생성

```bash
python3 build_data.py
```

## 로컬 실행

```bash
python3 -m http.server 8765
```
