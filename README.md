## 구성

- **1부 개념 카드 12장** — 정의는 W3C·ICA 표준 그대로, 예시는 전부 『대한민국 국회를 말하다 08 정세균』.
  1 온톨로지란 · 2 클래스/인스턴스 · 3 리터럴과 객체 속성 · 4 트리플·지식그래프 · 5 식별자 · 6 도메인/레인지 ·
  7 RDF·RDFS·OWL · 8 전거레코드 · 9 전거≠분류≠시소러스 · 10 RiC-CM · 11 RiC-O · 12 SPARQL
- **장마다 드래그 연습 14개** — 조각을 상자·트리플 칸에 끌어다 놓고 채점.
  오답에는 왜 틀렸는지가 붙고, **맞았을 때도 그 장에 나온 속성의 도메인·레인지·역방향을 원본 정의로 짚어 줌**
- **2부 그라운딩 워크벤치** — 원문 준비 → 개체 추출 → 클래스 배정 → 전거 매핑 → 트리플 잇기 → 검증 → 산출.
  준비된 8단락 말고 **내 원문**(txt·md·docx·hwpx·pdf 첨부 또는 붙여넣기)으로도 돌릴 수 있음
- **3부 트리플이 화면이 될 때** — 2부가 낸 TTL 을 그대로 올려 연표·관계망·SPARQL·비교 네 화면을 띄움.
  코딩은 하지 않음. 화면은 그래프에 **있는 것만** 그리므로 빠뜨린 것이 빈자리로 드러남

## 특징

- **정적 파일만.** 서버 로직 없음 — 25명 이상이 동시에 써도 부하 없음.
  외부 코드는 `vendor/pdf.js` 와 `vendor/oxigraph` 둘뿐이고 저장소에 동봉되어 **오프라인에서도 그대로 동작**함.
  API 키는 내 원문을 AI로 추출할 때와 3부 ④ 비교에만 쓰는 선택 사항
- **3부의 SPARQL 은 진짜 엔진.** 오후 스타터킷과 같은 Oxigraph(브라우저 안에서 도는 SPARQL 1.1)를 쓰되,
  CDN 이 아니라 `vendor/oxigraph/` 에 동봉함(3.5 MB · **3부를 열 때만** 내려받음).
  질의문 오류는 엔진이 낸 그대로 보여 주고, 자동으로 붙는 접두사 4줄만큼 밀린 줄 번호는 되돌려 적음
- **연표·관계망은 라이브러리 없이 직접 그림.** vis.js·D3 를 쓰지 않음 —
  연표는 실제 글자 폭을 재서 부딪히면 층을 내리고, 관계망은 캔버스에 힘 기반 배치(가장 많이 이어진 개체를 가운데 고정)
- **AI로 한꺼번에 추출** 버튼 하나로 개체·클래스·트리플이 통째로 들어옴. 8단락 전부 준비돼 있음
- AI 추출은 **사전 계산본**(API 키 불필요). Claude가 실제로 뽑은 결과이며 **틀린 항목이 의도적으로 섞여** 있음.
  심어 둔 정오 표시가 화면 ⑥ 검증 규칙과 어긋나면 `build_data.py` 가 빌드를 중단함
- 원문은 총서 PDF에서 뽑은 것이라 쪽 넘김 자국이 있었음 — 동그라미 기호(●)와 갈라진 띄어쓰기 45건을 보정.
  낱말은 하나도 바꾸지 않았고, 쪽 경계에서 잘린 문장은 `…` 로 표시
- 도메인·레인지가 선택지를 실시간으로 좁힘 (⑤단계) — 온톨로지가 환각을 줄이는 원리를 손으로 체험
- **목적어를 손으로 세울 수 있음** (⑤단계) — 개최장소처럼 원문에 이름이 없지만 아는 것.
  클래스는 고른 속성의 레인지로 이미 정해져 있어 그 안에서만 담기고, 개체 목록에 **“직접”** 표시가 붙음
- **개체의 식별자는 “이름”** (`idOf`). 같은 이름을 두 클래스로 담으면 ⑤에서 고른 것과 ⑥의 판정이 어긋나므로,
  AI 추출은 중복을 하나로 합쳐 무엇을 버렸는지 알리고, ⑥은 남은 중복을 “규칙1 이름 중복”으로 잡음
- 검증 6종 규칙 + 책 뒤 찾아보기와 재현율 대조
- **실패마다 “고치는 법”을 붙임** (⑥). 규칙 이름만으로는 다음 손이 안 나가므로, 사유 아래에
  무엇을 어디서 고칠지와 ③·⑤ 바로가기를 함께 표시. 도메인·레인지 위반은 **두 클래스를 실제로 이을 수 있는
  속성을 찾아 이름을 대 줌**(예: `Person → CorporateBody` → `isOrWasMemberOf`).
  권하는 클래스는 ③ 드롭다운에 있는 Core 12개로만 거름 — `Thing`처럼 고를 수 없는 것을 권하지 않도록
- **④ 전거 매핑은 “⑦에서 어느 URI를 쓸지” 가르는 단계.** 매칭되면 전거 URI(`ric:agent-071`),
  안 되면 임시 URI(`ric:local-이름`)를 화면에 그대로 보여 줌. 신규 후보는 **등록되지 않고 격리**되며
  전거 담당자에게 넘길 **CSV로 내보낼 수 있음**. UUID·VIAF·Wikidata 연결은 이 실습 범위 밖이지만,
  RiC-O 어느 자리에 붙는지(`rico:hasOrHadIdentifier` → `rico:Identifier` + `rico:hasIdentifierType`)는 접힘상자로 설명
- 내 원문에는 사전 계산본이 없으므로 **규칙 추출**이 기본 — AI가 아니라 브라우저 안에서 도는 글자 패턴 찾기
  (전거 90명 이름 일치 + 연도·법령·정당·직위·사건 접미사). 문맥을 읽지 않아 거칠게 뽑히고, 그 거칢이 교육 재료
- **AI 추출은 Anthropic · OpenAI · Google 중에서 고름.** 제공자별로 키와 모델 이름을 따로 저장하며
  키는 이 브라우저 localStorage 에만 들어감. 셋 다 각 API의 구조적 출력 기능(도구 호출 / JSON 모드)으로
  형식을 강제해, 앞뒤 군말이나 길이 초과로 파싱이 깨지지 않게 함
- **AI 추출 뒤에 쓴 토큰과 어림 비용을 표시.** 토큰 수는 API가 응답에 실어 보내는 실제 값이고,
  비용은 `app.js` 의 `PRICES` 단가표(100만 토큰당 달러)로 곱한 어림값 + 세션 누적.
  Anthropic 공식가(2026-06 기준)만 넣어 두었고, 단가가 없는 모델은 토큰 수만 보여 줌.
  사전 계산본·규칙 추출처럼 API를 부르지 않은 경우엔 “토큰 0”이라고 밝혀, 빈칸을 고장으로 오해하지 않게 함
- **`index.html` 의 스크립트 태그에 `?v=YYYYMMDD` 캐시 무효화 표시.**
  정적 파일만 올리는 구조라 서버 캐시 헤더를 못 건드림 — **파일을 고치면 이 날짜를 함께 올려야**
  브라우저(특히 워크숍 참가자들)가 옛 `app.js` 를 계속 쓰지 않음
- 파일에서 읽어들인 글의 각주 표시(●)·글머리 기호·폭 없는 공백은 자동으로 걷어 냄
- **출처 앵커는 자동.** 내 원문을 넣을 때 쪽 칸을 비워 두면 PDF는 **실제 쪽 번호**를(pdf.js 로 쪽 경계를 읽음),
  그 밖의 글은 `1단락` `2단락` … 을 자동으로 담. ⑥ 규칙6(출처 앵커)이 빈칸 때문에 터지지 않음
- 단락을 마칠 때마다 세션에 쌓여, 마지막에 **한 파일로 합쳐 내려받기**
- 11장에서 **RiC-O 1.1 전체 어휘**(클래스 107 · 객체속성 480 · 데이터속성 75)를 펼쳐 보고 검색.
  이 강의용 부분집합(Core 12·30 / Extended 10·20)도 같은 표에서 갈라 봄
- 11장에 **n-ary 릴레이션 패턴** 해설 — 트리플 한 줄로는 재임기간·근거·확실성을 붙일 수 없다는 문제부터
  `rico:PositionHoldingRelation` 예시, RDF 리이피케이션·RDF-star·3-홉과의 구별까지
- 프로파일을 **RDF/XML · Turtle · JSON-LD · CSV**로 내려받기. 세 직렬화 모두 트리플 216개로 동일

## 데이터 재생성

```bash
python3 build_data.py    # 전거·정답지·원문·Core 어휘 → data.js
python3 build_vocab.py   # RiC-O 원본 → vocab/rico-full.json + downloads/
```

`build_vocab.py` 는 `../01-profile/RiC-O_1-1.rdf` 를 직접 파싱합니다. 화면에 뜨는
클래스·속성 개수는 전부 이 파싱 결과이며 손으로 적은 값이 아닙니다.

전거 마스터는 부록 표를 파싱한 125건에서 **2건을 뺀 123건**입니다. 제5대 국회는 양원제라
표에 `민의원`·`참의원` 이라는 **칸 제목 줄**이 있는데 파서가 그것을 사람 이름으로 읽었습니다.
그 대수의 실제 의장(곽상훈·민의원 / 백낙준·참의원)은 각각 별도 행으로 이미 들어와 있어,
두 줄을 지워도 잃는 정보가 없습니다. `agent-NNN` 은 이름 가나다순 일련번호라 이때 함께 밀립니다
(정세균 `agent-072` → `agent-071`).

## 배포

정적 파일이므로 GitHub Pages에 그대로 올리면 됩니다.
`downloads/RiC-O_1-1.rdf`(1.6 MB)·`.ttl`(0.9 MB) 이 함께 올라가야 11장 내려받기가 동작하고,
`vendor/oxigraph/web_bg.wasm`(3.5 MB) 이 함께 올라가야 3부의 SPARQL 이 동작합니다.
`web.js` 가 `new URL('web_bg.wasm', import.meta.url)` 로 찾으므로 **둘은 같은 폴더에** 있어야 합니다.
